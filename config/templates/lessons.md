# AI Rules of Engagement
1. **Real Data First**: Never use mock data if a real API or database can be connected.
2. **Test-Driven**: Write the test for a feature *before* writing the implementation code.
3. **Atomic Changes**: Do not refactor unrelated code while working on a specific task.
4. **Context Management**: If a chat reaches 20+ messages, summarize the state and signal for a "Fresh Start."
5. **No Hallucinations**: If a library or method is unknown, ask for clarification instead of guessing.
